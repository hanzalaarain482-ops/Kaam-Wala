# Kaam-Wala — HTML, CSS, JavaScript Demo

This repository contains only a static, responsive, inDrive-style service-booking **demo**.

## Files
- `index.html` — app interface
- `style.css` — responsive design
- `app.js` — interactive booking logic

## Open
Open `index.html` using VS Code Live Server or any static web host. The map uses Leaflet and OpenStreetMap tiles from the internet. Browser GPS requires user permission and HTTPS or localhost.

## Demo features
Service selection, map pin and browser GPS, city/area selection, saved locations stored in your browser, sample automatic minimum prices, price increases, simulated search radius and bids, fictional moving technician, customer/partner/admin preview screens.

**Important:** There is no real backend, user registration, technician dispatch, genuine worker live GPS, real chat/calls or payments. The technician movement and offers are simulations. Do not use this demo to arrange actual services.
