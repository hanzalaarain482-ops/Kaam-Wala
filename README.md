# BulaoJi / Kaam-Wala

Service marketplace website project (customer, technician, admin).

This GitHub repository is currently being populated from the BulaoJi website source archive. The full source ZIP is available in the original ChatGPT conversation. The web app requires Supabase database setup and public project configuration before it can run.

**Status:** development starter, not a fully launched production service. Live GPS, in-app voice calling and real payment processing are not implemented yet.
